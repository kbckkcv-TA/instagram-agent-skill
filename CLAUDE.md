# Instagram data for this repo

The user's Instagram working files live in `instagram/` at the repo root, **not** in
`~/.claude/instagram/`. Whenever an `ig-*` skill says to read or write
`~/.claude/instagram/<file>` (voice.md, swipe.md, log.md, plan.md, ...), use
`instagram/<file>` in this repo instead, and commit the change.

- `instagram/profile.md` - what the user sells, themes, this week's events, engagement accounts
- `instagram/voice.md` - voice guide (Egyptian Arabic)
- `instagram/plan.md` - current weekly plan from /ig-plan
- `instagram/log.md` - what was posted / commented
